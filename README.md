# Журнал посещаемости

Сайт для учёта посещаемости студентов колледжа. Преподаватель заполняет журнал, куратор указывает причины пропусков, администратор ведёт группы и расписание. Есть статистика и выгрузка в Excel.

Стек: Python 3.12, Django 5.2, PostgreSQL 17, HTML, CSS, JavaScript.
