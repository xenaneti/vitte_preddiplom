# Журнал посещаемости

Веб-приложение для учёта посещаемости студентов колледжа. Преподаватель заполняет журнал занятий, куратор уточняет причины пропусков, администратор ведёт студентов, группы и расписание. По данным журнала можно посмотреть статистику и выгрузить отчёты в Excel.

## Архитектура

Приложение построено на Django по клиент-серверной схеме. Браузер отправляет запрос, сервер проверяет права пользователя и данные формы, обращается к PostgreSQL через Django ORM и возвращает HTML-страницу или файл XLSX. Страницы формируются на сервере; JavaScript используется для отдельных действий в интерфейсе.

## Структура проекта

- `config` — настройки проекта, маршруты и запуск приложения;
- `accounts` — вход, роли пользователей и личный кабинет;
- `college` — студенты, группы, справочники и расписание;
- `journal` — отметки, история изменений, статистика и отчёты;
- `support` — обращения пользователей;
- `templates` и `static` — шаблоны страниц, стили и скрипты.

## Тестовые учётные записи

- Администратор — `administrator`;
- преподаватель — `teacher1` и `teacher2`;
- куратор — `curator1` и `curator2`.

Стек: Python 3.12, Django 5.2, PostgreSQL 17, HTML, CSS, JavaScript.
